# Principles of Programming Projects

Welcome! I’m Kristina Garland. My background is in customer service and account resolution, and I enjoy helping people and using technology to solve problems.

This portfolio documents my learning as I study CSE 110: Principles of Programming through Arizona State University Universal Learner Courses.

## My Goals

* Learn how to break problems into manageable steps.
* Write clear Java programs.
* Test my work and understand how to fix errors.
* Apply programming skills to practical situations.

## Skills I Plan to Practice

* Variables and data types
* Decisions and loops
* Methods
* Arrays
* Classes and objects
* Basic searching and sorting

## What I Will Share

Each original practice project will include an explanation of its purpose, the code, instructions for running it, and examples of the results.

I will also document what I learned, challenges I encountered, and how I checked that the program worked.
